Notebook ini memperluas contoh PFL sebelumnya dengan **beberapa strategi agregasi federated**, agar bisa dibandingkan performanya pada kondisi data **non-IID** (data dummy/sintetis).

Strategi yang dibahas & diimplementasikan:

| Strategi | Ide Utama | Arsitektur |
|---|---|---|
| **FedAvg** | Rata-rata tertimbang parameter model dari semua klien | Centralized |
| **FedProx** | FedAvg + regularisasi L2 (proximal term) agar model lokal tidak terlalu jauh dari model global → lebih stabil di data heterogen | Centralized |
| **SCAFFOLD** | Memakai *control variates* untuk mengoreksi arah update tiap klien → mengatasi *client drift* | Centralized |
| **FedBN** | Layer *Batch Normalization* tetap lokal (tidak disinkronkan) → mengatasi *feature shift* antar perangkat | Centralized |
| **Clustered FL (CFL)** | Klien dikelompokkan (cluster) berdasarkan kemiripan data, agregasi dilakukan terpisah per klaster | Centralized (multi-model) |
| **Decentralized FL (Gossip)** | Tidak ada server pusat — tiap klien bertukar & merata-rata parameter langsung dengan "tetangga" (peer-to-peer) | Decentralized |

Untuk **FedAvg** dan **FedProx**, kita pakai strategi bawaan Flower (`flwr.server.strategy.FedAvg` dan `FedProx`).
Untuk **SCAFFOLD**, **FedBN**, **CFL**, dan **Decentralized/Gossip**, Flower belum menyediakan strategi bawaan (ini algoritma riset/khusus), sehingga kita implementasikan secara manual dengan loop federated sederhana, memakai fungsi `train`/`evaluate` dan konsep client/server yang sama seperti pola Flower — supaya tetap konsisten dan mudah dibandingkan.

Setelah semua strategi dijalankan, kita bandingkan **akurasi model personal (setelah fine-tuning lokal)** di setiap strategi.
""")

md("""## 2. Data Dummy Non-IID (6 Klien, 2 Kelompok)

Kita buat **6 klien**, terbagi dalam **2 kelompok tersembunyi** (mensimulasikan misalnya "kantor cabang Jakarta" vs "kantor cabang Surabaya") yang punya karakteristik data agak berbeda. Ini berguna khususnya untuk mendemonstrasikan **Clustered FL**.""")

code("""import numpy as np
import torch
import torch.nn as nn
from torch.utils.data import TensorDataset, DataLoader
from collections import OrderedDict
import copy

N_FEATURES = 10
NUM_CLIENTS = 6
# kelompok tersembunyi: client 0,1,2 = grup A ; client 3,4,5 = grup B
CLIENT_GROUP = {0: "A", 1: "A", 2: "A", 3: "B", 4: "B", 5: "B"}
GROUP_OFFSET = {"A": -1.5, "B": 1.5}

def generate_client_data(client_id: int, n_samples: int = 200, seed: int = 42):
    rng = np.random.default_rng(seed + client_id)
    group_offset = GROUP_OFFSET[CLIENT_GROUP[client_id]]

    # bias = offset kelompok (besar) + variasi kecil antar individu klien
    client_bias = rng.normal(loc=group_offset, scale=0.3, size=N_FEATURES)
    X = rng.normal(loc=client_bias, scale=1.0, size=(n_samples, N_FEATURES))

    true_weights = rng.normal(loc=0.5, scale=1.0, size=N_FEATURES)
    logits = X @ true_weights + rng.normal(0, 0.5, size=n_samples)
    y = (logits > np.median(logits)).astype(np.float32)

    X_tensor = torch.tensor(X, dtype=torch.float32)
    y_tensor = torch.tensor(y, dtype=torch.float32).unsqueeze(1)
    return TensorDataset(X_tensor, y_tensor)


def get_client_loaders(client_id: int, batch_size: int = 16):
    dataset = generate_client_data(client_id)
    n_train = int(0.8 * len(dataset))
    n_val = len(dataset) - n_train
    train_set, val_set = torch.utils.data.random_split(dataset, [n_train, n_val])
    train_loader = DataLoader(train_set, batch_size=batch_size, shuffle=True)
    val_loader = DataLoader(val_set, batch_size=batch_size, shuffle=False)
    return train_loader, val_loader

CLIENT_LOADERS = {cid: get_client_loaders(cid) for cid in range(NUM_CLIENTS)}
print("Data dummy siap untuk", NUM_CLIENTS, "klien, grup:", CLIENT_GROUP)""")

md("""## 3. Model (dengan Batch Normalization untuk mendukung FedBN)""")

code("""class SimpleClassifier(nn.Module):
    def __init__(self, n_features: int = N_FEATURES):
        super().__init__()
        self.fc1 = nn.Linear(n_features, 16)
        self.bn1 = nn.BatchNorm1d(16)
        self.fc2 = nn.Linear(16, 8)
        self.bn2 = nn.BatchNorm1d(8)
        self.fc3 = nn.Linear(8, 1)
        self.act = nn.ReLU()
        self.out = nn.Sigmoid()

    def forward(self, x):
        x = self.act(self.bn1(self.fc1(x)))
        x = self.act(self.bn2(self.fc2(x)))
        return self.out(self.fc3(x))

# helper: nama parameter yang termasuk layer BatchNorm (dipakai khusus FedBN)
def bn_param_names(model):
    return [n for n, _ in model.named_parameters() if "bn" in n] + \\
           [n for n, _ in model.named_buffers() if "bn" in n]""")

md("""## 4. Fungsi Bantu Umum: Parameter, Training, Evaluasi

Fungsi `train_fedprox` menambahkan **proximal term** (selisih L2 antara bobot lokal dan bobot global) ke dalam loss, sesuai definisi FedProx:

$$ \\mathcal{L}_{prox} = \\mathcal{L}_{task} + \\frac{\\mu}{2} \\| w_{local} - w_{global} \\|^2 $$""")

code("""def get_parameters(model):
    return [val.detach().clone() for val in model.state_dict().values()]

def set_parameters(model, parameters):
    keys = model.state_dict().keys()
    state_dict = OrderedDict({k: v.clone() for k, v in zip(keys, parameters)})
    model.load_state_dict(state_dict, strict=True)

def train(model, loader, epochs=1, lr=0.05):
    criterion = nn.BCELoss()
    optimizer = torch.optim.SGD(model.parameters(), lr=lr)
    model.train()
    for _ in range(epochs):
        for X, y in loader:
            optimizer.zero_grad()
            loss = criterion(model(X), y)
            loss.backward()
            optimizer.step()

def train_fedprox(model, loader, global_params, mu=0.1, epochs=1, lr=0.05):
    \"\"\"Training lokal dengan proximal term (FedProx).\"\"\"
    criterion = nn.BCELoss()
    optimizer = torch.optim.SGD(model.parameters(), lr=lr)
    global_tensors = [p.clone() for p in global_params]
    model.train()
    for _ in range(epochs):
        for X, y in loader:
            optimizer.zero_grad()
            loss = criterion(model(X), y)
            prox_term = 0.0
            for local_p, global_p in zip(model.parameters(), global_tensors):
                prox_term += ((local_p - global_p) ** 2).sum()
            loss = loss + (mu / 2) * prox_term
            loss.backward()
            optimizer.step()

def evaluate(model, loader):
    criterion = nn.BCELoss()
    model.eval()
    total_loss, correct, total = 0.0, 0, 0
    with torch.no_grad():
        for X, y in loader:
            output = model(X)
            loss = criterion(output, y)
            total_loss += loss.item() * len(y)
            preds = (output > 0.5).float()
            correct += (preds == y).sum().item()
            total += len(y)
    return total_loss / total, correct / total

def personalize(global_params, client_id, epochs=5, lr=0.02):
    \"\"\"Fine-tuning lokal singkat dari model global -> model personal, lalu evaluasi.\"\"\"
    model = SimpleClassifier()
    set_parameters(model, global_params)
    train_loader, val_loader = CLIENT_LOADERS[client_id]
    train(model, train_loader, epochs=epochs, lr=lr)
    _, acc = evaluate(model, val_loader)
    return acc

RESULTS = {}  # menyimpan rata-rata akurasi personalisasi tiap strategi""")

md("""## 5. Strategi 1 — FedAvg (native Flower)

`FedAvg` adalah baseline: server mengambil rata-rata tertimbang parameter dari semua klien.""")

code("""import flwr as fl
from flwr.server.strategy import FedAvg

class FedAvgClient(fl.client.NumPyClient):
    def __init__(self, cid):
        self.cid = cid
        self.model = SimpleClassifier()
        self.train_loader, self.val_loader = CLIENT_LOADERS[cid]

    def get_parameters(self, config):
        return [p.numpy() for p in get_parameters(self.model)]

    def fit(self, parameters, config):
        set_parameters(self.model, [torch.tensor(p) for p in parameters])
        train(self.model, self.train_loader, epochs=1, lr=0.05)
        return [p.numpy() for p in get_parameters(self.model)], len(self.train_loader.dataset), {}

    def evaluate(self, parameters, config):
        set_parameters(self.model, [torch.tensor(p) for p in parameters])
        loss, acc = evaluate(self.model, self.val_loader)
        return loss, len(self.val_loader.dataset), {"accuracy": acc}

def fedavg_client_fn(cid):
    return FedAvgClient(int(cid)).to_client()

strategy_fedavg = FedAvg(
    fraction_fit=1.0, fraction_evaluate=1.0,
    min_fit_clients=NUM_CLIENTS, min_evaluate_clients=NUM_CLIENTS, min_available_clients=NUM_CLIENTS,
)

history_fedavg = fl.simulation.start_simulation(
    client_fn=fedavg_client_fn,
    num_clients=NUM_CLIENTS,
    config=fl.server.ServerConfig(num_rounds=8),
    strategy=strategy_fedavg,
)

# ambil parameter global akhir dari salah satu client sbg acuan personalisasi
final_model = SimpleClassifier()
tmp_client = FedAvgClient(0)
# (Flower tidak langsung expose parameter akhir dari simulate; kita re-run 1 fit manual utk ambil param global)
# --> lihat cell berikutnya untuk cara praktis mengambil global params akhir""")

md("""> **Catatan teknis:** `fl.simulation.start_simulation` tidak langsung mengembalikan bobot global akhir. Cara paling praktis untuk demo ini adalah menjalankan proses federated secara **manual (loop eksplisit)** — polanya identik dengan yang dilakukan Flower di balik layar (`get_parameters` → kirim ke klien → `fit` → agregasi FedAvg), tapi kita jadi punya akses langsung ke bobot global akhir untuk tahap personalisasi. Pendekatan ini juga yang kita pakai secara konsisten untuk SCAFFOLD, FedBN, CFL, dan Decentralized FL di bawah, supaya semua strategi bisa dibandingkan dengan adil.""")

code("""def fedavg_manual(num_rounds=8):
    global_model = SimpleClassifier()
    global_params = get_parameters(global_model)

    for rnd in range(num_rounds):
        client_updates = []
        client_sizes = []
        for cid in range(NUM_CLIENTS):
            local_model = SimpleClassifier()
            set_parameters(local_model, global_params)
            train_loader, _ = CLIENT_LOADERS[cid]
            train(local_model, train_loader, epochs=1, lr=0.05)
            client_updates.append(get_parameters(local_model))
            client_sizes.append(len(train_loader.dataset))

        total = sum(client_sizes)
        new_params = []
        for param_idx in range(len(global_params)):
            weighted_sum = sum(
                client_updates[i][param_idx] * (client_sizes[i] / total)
                for i in range(NUM_CLIENTS)
            )
            new_params.append(weighted_sum)
        global_params = new_params

    return global_params

global_params_fedavg = fedavg_manual(num_rounds=8)
accs = [personalize(global_params_fedavg, cid) for cid in range(NUM_CLIENTS)]
RESULTS["FedAvg"] = np.mean(accs)
print("FedAvg -> rata-rata akurasi personalized:", round(np.mean(accs), 3))""")

Sama seperti FedAvg, tapi training lokal menggunakan `train_fedprox` yang menambahkan **proximal term** agar bobot lokal tidak terlalu jauh menyimpang dari bobot global — berguna saat data antar klien sangat heterogen (non-IID).""")

code("""def fedprox_manual(num_rounds=8, mu=0.1):
    global_model = SimpleClassifier()
    global_params = get_parameters(global_model)

    for rnd in range(num_rounds):
        client_updates = []

            train_loader, _ = CLIENT_LOADERS[cid]
            train_fedprox(local_model, train_loader, global_params, mu=mu, epochs=1, lr=0.05)

        total = sum(client_sizes)
        global_params = [
            sum(client_updates[i][p] * (client_sizes[i] / total) for i in range(NUM_CLIENTS))
            for p in range(len(global_params))
        ]

    return global_params

global_params_fedprox = fedprox_manual(num_rounds=8, mu=0.1)
accs = [personalize(global_params_fedprox, cid) for cid in range(NUM_CLIENTS)]
RESULTS["FedProx"] = np.mean(accs)
print("FedProx -> rata-rata akurasi personalized:", round(np.mean(accs), 3))""")

md("""## 7. Strategi 3 — SCAFFOLD

SCAFFOLD memakai **control variates** — satu di server (`c_global`) dan satu per klien (`c_i`) — untuk mengoreksi arah gradien lokal supaya tidak "melenceng" jauh dari arah update global (mengatasi *client drift*). Implementasi di bawah adalah versi sederhana dari SCAFFOLD:

Update lokal: `w = w - lr * (grad - c_i + c_global)`

Setelah training, `c_i` diperbarui berdasarkan seberapa jauh model lokal bergerak.""")

code("""def train_scaffold(model, loader, c_global, c_i, epochs=1, lr=0.05):
    optimizer = torch.optim.SGD(model.parameters(), lr=lr)
    criterion = nn.BCELoss()
    model.train()
    for _ in range(epochs):
        for X, y in loader:
            optimizer.zero_grad()
            loss = criterion(model(X), y)
            loss.backward()
            # koreksi gradien dengan control variates
            with torch.no_grad():
                for p, cg, ci in zip(model.parameters(), c_global, c_i):
                    if p.grad is not None:
                        p.grad += (cg - ci)
            optimizer.step()

def scaffold_manual(num_rounds=8, lr=0.05):
    global_model = SimpleClassifier()
    global_params = get_parameters(global_model)
    c_global = [torch.zeros_like(p) for p in global_params]
    c_locals = {cid: [torch.zeros_like(p) for p in global_params] for cid in range(NUM_CLIENTS)}

    for rnd in range(num_rounds):
        client_updates, client_sizes, delta_c_sum = [], [], [torch.zeros_like(p) for p in global_params]

        for cid in range(NUM_CLIENTS):
            local_model = SimpleClassifier()
            set_parameters(local_model, global_params)
            train_loader, _ = CLIENT_LOADERS[cid]

            w_before = [p.clone() for p in get_parameters(local_model)]
            train_scaffold(local_model, train_loader, c_global, c_locals[cid], epochs=1, lr=lr)
            w_after = get_parameters(local_model)

            # update control variate lokal: c_i_new = c_i - c_global + (w_before - w_after) / (lr * steps)
            steps = max(1, len(train_loader))
            c_i_new = [
                ci - cg + (wb - wa) / (lr * steps)
                for ci, cg, wb, wa in zip(c_locals[cid], c_global, w_before, w_after)
            ]
            delta_c_sum = [ds + (cin - ci) for ds, cin, ci in zip(delta_c_sum, c_i_new, c_locals[cid])]
            c_locals[cid] = c_i_new

            client_updates.append(w_after)
            client_sizes.append(len(train_loader.dataset))

        # agregasi FedAvg untuk bobot model
        total = sum(client_sizes)
        global_params = [
            sum(client_updates[i][p] * (client_sizes[i] / total) for i in range(NUM_CLIENTS))
            for p in range(len(global_params))
        ]
        # update control variate global (rata-rata perubahan)
        c_global = [cg + ds / NUM_CLIENTS for cg, ds in zip(c_global, delta_c_sum)]

    return global_params

global_params_scaffold = scaffold_manual(num_rounds=8)
accs = [personalize(global_params_scaffold, cid) for cid in range(NUM_CLIENTS)]
RESULTS["SCAFFOLD"] = np.mean(accs)
print("SCAFFOLD -> rata-rata akurasi personalized:", round(np.mean(accs), 3))""")

# =================================================================
md("""## 8. Strategi 4 — FedBN

Idenya sederhana: **layer Batch Normalization (bn1, bn2) tidak pernah disinkronkan ke server** — tetap tersimpan lokal di tiap klien selama proses federated berjalan. Hanya layer lain (`fc1, fc2, fc3`) yang diagregasi. Ini efektif menangani *feature shift* karena BN sangat sensitif terhadap distribusi data lokal.""")

code("""def fedbn_manual(num_rounds=8):
    global_model = SimpleClassifier()
    global_full_params = get_parameters(global_model)  # termasuk BN, tapi BN tidak akan diagregasi
    param_names = list(global_model.state_dict().keys())
    bn_names = set(bn_param_names(global_model))
    non_bn_idx = [i for i, n in enumerate(param_names) if n not in bn_names]

    # tiap klien punya BN lokal sendiri, diinisialisasi dari model awal lalu tidak pernah di-overwrite oleh global
    local_bn_state = {cid: [global_full_params[i].clone() for i, n in enumerate(param_names) if n in bn_names]
                       for cid in range(NUM_CLIENTS)}
    bn_idx = [i for i, n in enumerate(param_names) if n in bn_names]

    global_params = global_full_params

    for rnd in range(num_rounds):
        client_updates, client_sizes = [], []
        for cid in range(NUM_CLIENTS):
            local_model = SimpleClassifier()
            # gabungkan: layer non-BN dari global, layer BN dari state lokal klien
            merged = list(global_params)
            for j, idx in enumerate(bn_idx):
                merged[idx] = local_bn_state[cid][j]
            set_parameters(local_model, merged)

            train_loader, _ = CLIENT_LOADERS[cid]
            train(local_model, train_loader, epochs=1, lr=0.05)

            updated = get_parameters(local_model)
            # simpan kembali BN lokal (tidak dikirim ke server)
            local_bn_state[cid] = [updated[idx].clone() for idx in bn_idx]

            client_updates.append(updated)
            client_sizes.append(len(train_loader.dataset))

        # server hanya mengagregasi parameter NON-BN
        total = sum(client_sizes)
        new_global = list(global_params)
        for idx in non_bn_idx:
            new_global[idx] = sum(client_updates[i][idx] * (client_sizes[i] / total) for i in range(NUM_CLIENTS))
        global_params = new_global

    # kembalikan dict: global non-BN params + BN lokal per klien (untuk tahap personalisasi)
    return global_params, local_bn_state, bn_idx

global_params_fedbn, local_bn_state_fedbn, bn_idx_fedbn = fedbn_manual(num_rounds=8)

def personalize_fedbn(cid, epochs=5, lr=0.02):
    model = SimpleClassifier()
    merged = list(global_params_fedbn)
    for j, idx in enumerate(bn_idx_fedbn):
        merged[idx] = local_bn_state_fedbn[cid][j]
    set_parameters(model, merged)
    train_loader, val_loader = CLIENT_LOADERS[cid]
    train(model, train_loader, epochs=epochs, lr=lr)
    _, acc = evaluate(model, val_loader)
    return acc

accs = [personalize_fedbn(cid) for cid in range(NUM_CLIENTS)]
RESULTS["FedBN"] = np.mean(accs)
print("FedBN -> rata-rata akurasi personalized:", round(np.mean(accs), 3))""")

# =================================================================
md("""## 9. Strategi 5 — Clustered Federated Learning (CFL)

Alih-alih 1 model global untuk semua klien, klien dikelompokkan ke dalam beberapa **klaster** (berdasarkan kemiripan update model / data), lalu agregasi FedAvg dilakukan **terpisah per klaster**.

Untuk demo ini, kita pakai pendekatan praktis: jalankan 1 ronde awal FedAvg bersama untuk mendapat arah update tiap klien, hitung kemiripan (cosine similarity) antar update, lalu kelompokkan klien berdasarkan kemiripan tersebut (di dunia nyata, biasanya dilakukan otomatis lewat clustering seperti hierarchical clustering).""")

code("""def flatten(params):
    return torch.cat([p.flatten() for p in params])

def cluster_clients_by_update_similarity(global_params, n_clusters=2):
    updates = {}
    for cid in range(NUM_CLIENTS):
        local_model = SimpleClassifier()
        set_parameters(local_model, global_params)
        train_loader, _ = CLIENT_LOADERS[cid]
        train(local_model, train_loader, epochs=1, lr=0.05)
        delta = [a - b for a, b in zip(get_parameters(local_model), global_params)]
        updates[cid] = flatten(delta)

    # cosine similarity matrix sederhana
    ids = list(updates.keys())
    sims = np.zeros((len(ids), len(ids)))
    for i, ci in enumerate(ids):
        for j, cj in enumerate(ids):
            sims[i, j] = torch.nn.functional.cosine_similarity(
                updates[ci].unsqueeze(0), updates[cj].unsqueeze(0)
            ).item()

    # clustering sederhana: pakai KMeans dari sklearn kalau ada, else agglomerative manual 2-cluster
    from sklearn.cluster import KMeans
    km = KMeans(n_clusters=n_clusters, n_init=10, random_state=0)
    labels = km.fit_predict(sims)
    clusters = {}
    for cid, label in zip(ids, labels):
        clusters.setdefault(int(label), []).append(cid)
    return clusters

def fedavg_on_subset(client_ids, num_rounds=8):
    global_model = SimpleClassifier()
    global_params = get_parameters(global_model)
    for rnd in range(num_rounds):
        client_updates, client_sizes = [], []
        for cid in client_ids:
            local_model = SimpleClassifier()
            set_parameters(local_model, global_params)
            train_loader, _ = CLIENT_LOADERS[cid]
            train(local_model, train_loader, epochs=1, lr=0.05)
            client_updates.append(get_parameters(local_model))
            client_sizes.append(len(train_loader.dataset))
        total = sum(client_sizes)
        global_params = [
            sum(client_updates[i][p] * (client_sizes[i] / total) for i in range(len(client_ids)))
            for p in range(len(global_params))
        ]
    return global_params

# 1) tentukan klaster
init_model = SimpleClassifier()
clusters = cluster_clients_by_update_similarity(get_parameters(init_model), n_clusters=2)
print("Hasil clustering klien:", clusters)

# 2) federated learning terpisah per klaster
cluster_global_params = {}
for label, members in clusters.items():
    cluster_global_params[label] = fedavg_on_subset(members, num_rounds=8)

# 3) personalisasi per klien memakai model global KLASTER-nya masing-masing
cfl_accs = []
for label, members in clusters.items():
    for cid in members:
        acc = personalize(cluster_global_params[label], cid)
        cfl_accs.append(acc)

RESULTS["Clustered FL"] = np.mean(cfl_accs)
print("Clustered FL -> rata-rata akurasi personalized:", round(np.mean(cfl_accs), 3))""")

md("""> **Catatan:** Karena data dummy kita sengaja dibuat dengan 2 grup tersembunyi (grup A: klien 0-2, grup B: klien 3-5), CFL idealnya berhasil menemukan pembagian klaster yang mendekati grup asli tersebut — jika hasil `clusters` di atas mengelompokkan `{0,1,2}` dan `{3,4,5}` secara terpisah, artinya CFL bekerja sesuai harapan.""")

# =================================================================
md("""## 10. Decentralized Federated Learning (DFL) — Gossip Protocol

Pada **DFL**, tidak ada server pusat. Tiap klien hanya bertukar parameter dengan **tetangganya** (topologi ring/cincin sederhana di sini), lalu merata-rata bobotnya sendiri dengan bobot tetangga. Setelah beberapa ronde "gosip", semua klien perlahan konvergen ke model yang mirip, meski prosesnya sepenuhnya peer-to-peer.""")

code("""def gossip_manual(num_rounds=8, lr=0.05):
    # tiap klien punya model sendiri dari awal
    client_params = {cid: get_parameters(SimpleClassifier()) for cid in range(NUM_CLIENTS)}

    # topologi ring: klien i bertetangga dengan (i-1) dan (i+1)
    def neighbors(cid):
        return [(cid - 1) % NUM_CLIENTS, (cid + 1) % NUM_CLIENTS]

    for rnd in range(num_rounds):
        # 1) tiap klien training lokal 1 epoch dari parameternya sendiri
        for cid in range(NUM_CLIENTS):
            local_model = SimpleClassifier()
            set_parameters(local_model, client_params[cid])
            train_loader, _ = CLIENT_LOADERS[cid]
            train(local_model, train_loader, epochs=1, lr=lr)
            client_params[cid] = get_parameters(local_model)

        # 2) gossip averaging: tiap klien rata-rata dgn parameter tetangganya (P2P, tanpa server)
        new_params = {}
        for cid in range(NUM_CLIENTS):
            neigh = neighbors(cid)
            all_ids = [cid] + neigh
            new_params[cid] = [
                sum(client_params[n][p] for n in all_ids) / len(all_ids)
                for p in range(len(client_params[cid]))
            ]
        client_params = new_params

    return client_params

gossip_final_params = gossip_manual(num_rounds=8)

# tiap klien personalisasi dari model hasil "gosip"-nya sendiri (bukan 1 model global bersama)
accs = [personalize(gossip_final_params[cid], cid) for cid in range(NUM_CLIENTS)]
RESULTS["Decentralized (Gossip)"] = np.mean(accs)
print("Decentralized FL (Gossip) -> rata-rata akurasi personalized:", round(np.mean(accs), 3))""")
